FG Combo Cue Trainer

指定フレームでビープ音と画面フラッシュを出す練習用ツールです（ローカルでそのまま動作）。

使い方:
  1. Cue Frames に 0,29,47 を入力。
  2. Loop Length Frames に 64 などを入力。
  3. Start を押す。
  4. 0F / 29F / 47F で音とフラッシュが出る。
  5. Stop または Reset で停止。

判定は requestAnimationFrame + performance.now() で行い、フレーム境界の通過を検出します。
